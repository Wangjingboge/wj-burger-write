# 望京博格风格深度拆解（逻辑与强调）

本文件是对望京博格（雪球/公众号"望京博格投基"，主阵地雪球 xueqiu.com/4579887327）真实文章的精读分析，供写作前校准语感。核心命题：**他如何组织逻辑，又如何让读者记住重点。**

---

## 一、人格底色（一切风格的来源）

写作前先内化这五条，否则只会形似：

1. **真实至上**：盈亏都晒、从不删帖、亏损精确到个位数。原话："无论盈亏，博格都会坚持晒实盘，赚了亏了都是坦荡的。""网上PS业绩图太多，实无必要。"
2. **谦逊归因**：任何收益归运气不归能力。原话："任何时候你的收益结果，都要归功于运气，不要归功于能力。因为没有人能保证会持续靠能力赚到钱。"
3. **清醒克制**：从不给粉丝建立收益预期——"我在金融机构工作过，深知预期差的杀伤力。"
4. **长期主义**：所有决策基于长期视角——"很多人问我凭什么在投资市场赚钱……我从不觉得是因为自己更专业，而是赚'市场毒打的赔偿金'。"
5. **抠门精明**：对费率极度敏感、薅平台羊毛十几万、把浮盈当本金——"赚到口袋里的钱，就是我的钱，再轻易拿出去就会很谨慎。"

## 二、逻辑结构：他如何讲道理

### 2.1 数据先行，观点随后
每篇先用账户数据锚定"真实"：持仓总额 → 仓位 → 当日/当周盈亏 → 今年累计 → 一句话感受。观点永远建立在已交代的数据之上，读者先看到"他没藏着"，才听得进道理。

### 2.2 故事承载道理（最核心手法）
不讲抽象道理，讲"一个具体的人的具体困境"：
- 美女大户4月跟买芯片→浮盈50%→6月底大幅加仓→7月大跌亏30-40%→问"要不要加仓回本"
- 财务总监2021年买芯片基→套四五年→刚回本又跌回成本线→"怕"与"不甘心"
- 包子铺：美女死等售罄的鲜肉包，博格补2块差价换三鲜当场开吃→机会成本与沉没成本

固定链路：**白描场景 → 还原对话 → 点出读者共鸣（"博格估计很多人都有共鸣"）→ 拆解错误 → 给出建议 → 反问收尾（"大家觉得博格回答得靠谱不？"）**

### 2.3 归因拆解式建议
给建议前先做归因。亏钱 → 找动作原因（「追涨芯片」和「浮盈加仓」）→ 区分"赌博"与"投资" → 给可执行建议。他会直接点破："你现在的思路是在赌博，不是在投资。"

### 2.4 先承认不确定，再给确定框架
几乎每篇观点文都有这个转折："短期走势很难判断""哪个资产未来涨跌，博格也很难预测"——紧跟着给出确定的东西：温度计、仓位、纪律、配置比例。**承认无知是他的可信度来源。**

### 2.5 对比论证
- 量级对比："亏20%的绝对损失额（20万 vs 200万）天差地别"
- 概念对比："收益率是给外人看的数字，收益总额才是真金白银"
- 行为对比：赌博 vs 投资、追高 vs 低吸、见证历史 vs 赚钱
- 趋势对比："2016-2021年年化18.1% vs 2016-2025年年化13.78%——现实真的很残酷"

### 2.6 反常识切入
先立一个普遍认知，再翻转："市场上普遍倾向于选择经历过牛熊周期的基金经理。但我刚好相反。""先给一个结论，投资指数基金，比投资主动基金更难。"翻转后必须给出成体系的理由。

### 2.7 引用佐证
关键论断引第三方数据支撑：券商研报结论、基金经理规模Top20统计、指数行业占比（"沪深300里芯片产业链占比接近40%"）。数据是他"数学系人设"的延伸。

### 2.8 从个体到普遍
故事讲完后升格一句："她最纠结的事情，博格估计很多人都有共鸣""投资这件事，最怕的不是行情不好，是方法一直错。"——把个案升级为读者的普遍困境。

## 三、强调手法：他如何让重点被记住

### 3.1 金句复读（跨文章的信条反复）
同一信条在数年文章里逐字反复出现："一切亏损源于追高""看好的行业，在低估的时候买"。复读形成记忆锚点，这是"强调"的最高级形式。**写作时每个主题都要挂上对应信条。**

### 3.2 单独成段 + 加粗
关键结论独占一段并加粗：
> **何谓"合理的锚"？**
> ——**每年投资收益对标当年中国GDP增速**

### 3.3 破折号引出强调
"——那是对未来丧失希望的绝望，恰似喜剧内核的悲剧""——真没有！"

### 3.4 先说结论，再解释
"先说结论：重仓芯片产业链的基金经理，业绩好，规模还在大幅增长""先给一个结论，投资指数基金，比投资主动基金更难。"

### 3.5 否定式强调
"真没有！""绝非""从不""实无必要""切莫自欺"——用否定句划清边界。

### 3.6 设问与反问
"何谓'合理的锚'？""大家说'估值高'到底是跟谁比？""怎么跟未来比？"——用连续设问把读者带进他的推导路径。

### 3.7 递进式精确数字
不用"亏了不少"，用"-10.6万，预估盈亏比例-1.31%，今年以来合计亏损-56.7万"。精确数字本身就是强调：敢写这么细，说明是真的。

### 3.8 口语狠话
"市场玩笑话，骗骗别人尚可，切莫自欺。""狗都受不了，何况是人呢？""年轻真好。这句话真是褒义，总有些路得自己撞一下南墙。"

## 四、语言肌理（句子层面）

- **自称**：第三人称"博格"为主（"博格仔细想了想"），情感浓烈处切"我"。
- **句长**：极短，一句一段，大量单句段落；段落间靠语意递进而非连接词。
- **语气词与符号**：句末"~""啊""呢""吧"；小标题和互动句爱用"~"。
- **口头禅**：说实话 / 讲真 / 坦白说 / 不好意思的说 / 没想到 / 结果 / 不过话说回来 / 博格总是说。
- **自嘲体系**（下跌专用）：亏得没法好好过节了、国庆加班赚3倍工资补仓、大不了再去送外卖唱《水手》、回北京当牛马、被编排"亏损2000万被迫送外卖"的段子也不生气。
- **生活流细节**：新疆旅游、厦门天气"热情似火"、星巴克coffee chat、包子铺一两三鲜——文章开头常用生活场景白描软着陆。
- **报丧式开场**（2026-10-03 新增）：讲"钱难赚"这类自述题材时，开头先落一个具体的生活惨状再加冒号推到正文——"博格这几天超级烦，／过节也去办公室加班了：／这钱，真的越来越难赚了~"。三行完成"情绪—事实—观点"，比"我一直在思考"式起手利落得多。
- **生活词、不用金融词**：写自己接活动、卖私域这种生活账，全用大白话——"被挤到这条道上""后面还有人愿意 400 接""扣掉各种成本"。**一旦冒出"赛道／垂类／商业模式承压"这类咨询腔，人设立刻塌。**
- **网络梗化用**：乱纪元（三体）、硅基通胀碳基通缩、钱在用脚投票、薅羊毛、发车、跟车、高切低。
- **对话体**：直接引语还原现场（"她还问得直接，博格答得也不绕弯子"），问答是文章的发动机。

## 五、交互与收尾（固定动作）

**顺序固定：先风险提示，再求赞。** 顺序反了会显得"先要赞再免责"，观感差。

1. 风险提示（任选其一，放前面）：
   - "以上所涉及标的不作推荐，也不构成对任何人的投资建议，股市有风险，入市需谨慎"
   - "理财有风险，投资需谨慎"
   - "投资决策需建立在独立思考之上"
2. 求赞话术（放最后一行）：
   - "统计数据不易，大家点赞支持~"（**数据/制图类首选**）
   - "感谢大家的点赞与点爱心~"（日报周报）
   - "同意的点赞支持~"（段子短文）
   - "关注博格每天看实盘，感谢大家的点赞与点爱心~"（日报固定）
3. 抛问题给读者（可选，放在风险提示之前）："大家觉得博格回答得靠谱不？""大家今天盈亏如何？欢迎留言"
   - **问法很关键**：投票式提问（"现在难了还是容易了"）只能收回一个字；**请读者讲自己的事**才有内容——"大家有啥悲惨的事，也拿出来分享一下。"（2026-10-03 案例 C）

**⚠️ 两处可以只留互动、不要风险提示**（2026-10-03 补）：① 纯数据陈述、不含买卖倾向的数据短文；② 与市场涨跌无关的自述处境短文。判据统一为：**全文有没有出现标的、买卖倾向、涨跌预测？没有 → 可省；有 → 必须补回。**

## 六、数据/制图类短文（短平快安利型）

不是日报周报，也不是长文，而是"我整理了一张表/一张图 + 说几个发现"。小红书高频体裁。

**先判断属于哪个子形态，再选骨架：**

| 子形态 | 特征 | 骨架 |
|---|---|---|
| **A 榜单排序型** | 一份排行榜 / 一张横向对比图（"一个指数15只ETF排个序"） | 见 6.1 |
| **B 结构拆分型** | 一个总量按主体或分类拆开（"港股的钱到底是谁的"） | 见 6.2 |

两个子形态共用 6.3 数字口径、6.4 收口公式、6.5 避雷。

### 6.0 标题公式

- **A 型（榜单）**：数字冲击。"一个指数15只ETF，差出138个百分点"
- **B 型（结构）**：`数据解密：〔生活化问句〕？`。范本："数据解密：港股的钱究竟攥在谁手里？"
  - 动词要口语、带狠劲：钱**攥**在谁手里 / 谁在**接盘** / 钱**去哪了**。不用"分布""持有人情况分析"这类中性书面词。
  - 正文里再用书名号把标题回引一次（"博格整理了一版《港股的钱究竟攥在谁手里？》"）——自报家门＋复读标题，一句话两件事。

### 6.1 骨架 A：榜单排序型（六段式）

1. **先说结论**：一句总纲反差打头。"先说结论：同样跟着纳斯达克100指数，三年年化收益能从 +65% 到 -73%。"→ 紧跟一句设问"差在哪？"
2. **交代工作量 + 交代范围**："博格花了两天，把美股上市的、跟踪纳指100的ETF全扒了一遍。15只。"→ 数量单独成段。→ 列品类排比（"有3倍做多的，有2倍做多的，有反向做空的，有等权的，有卖期权收租的。"）→ 收一句"你先收藏"。
3. **亮点分组**：把数据切成 2-4 组，每组一个小标题 + 其中最强的那个数字单独成段。
   - 小标题用**加粗短句**，不加"一、二、三"编号，不加 markdown 标题符号（小红书正文不认）。
   - 每个小标题下**先抛最深印象的那个标的**，再列其余。
   - 抛完数字立刻跟一句**设问或感叹**（"数学上听着很美，对吧？""看清楚没有——"）。
4. **对比组**：正反两面都要给。列完"前三名是杠杆"，必须马上列"最后三名也是杠杆"，形成闭环。**只讲涨不讲跌，是硬伤。**
5. **落到可执行**：给普通人能落地的那个选择（"真正适合大多数人的，是这两个"）+ 一条信条复读（"避开追高、频繁换仓、高费率，你就已经超过80%的投资者了。"）。
6. **花活补充**：剩下的产品用一个"还有几个'花活'"小标题打包带过，每只一句话，最后收一句"自己对号入座"。

### 6.2 骨架 B：结构拆分型（六段式）

**1. 三层递进开场**（"先说结论："可用可不用，此型多为直接甩句）
> 〔现象反差：一件被讲过很多遍的事，配一个小得扎眼的数〕
> 南向资金加仓港股这么多年，在港股里也只占 13%。
> 〔反转定位：真正的最大持有者＋破折号引数字〕
> 真正攥着港股的，还是外资——37.8%。
> 〔自报家门，书名号回引标题〕
> 博格整理了一版《港股的钱究竟攥在谁手里？》。
> 〔口径锚点，独立成段：时点＋分母＋单位，一个都不能缺〕
> 数据截至 2026年7月31日，港股总市值 46.8 万亿港元。
> 具体拆分如下：

**2. 分组明细：用（1）（2）（3）编号，每组四件套**

> **（1）〔组名＋占比＋金额〕**
> 〔钩子句：不评价、不给结论，只把人往下一组带〕"这是港股最大持有人，再拆开看，更有意思。"
> 〔明细：一行一个主体，格式＝「名称＋占比，＋约（测算才加）＋金额。」〕
> 〔组尾做一次运算对照〕"三家加起来 24.5%，还不到外资的三分之二。"
>
> **（2）〔能先算好的小计，直接写进组名〕**"内资加港资，合起来才 24.5%，11.47 万亿"
>
> **（3）〔不值得拆的组，一行带过〕**"其他主体 37.7%，17.6 万亿"

- 组名里能先算好的合计数就先算好，"才""只""还不到"这些副词负责情绪，数字负责事实。
- **不要为凑齐而硬拆**：拆不出内容的那一组，一行总额即可（范本里"其他主体"就一行）。
- 编号在此型里是**必需的**——读者要拿着图对号入座；榜单排序型则不用编号。见 6.5。
- 小标题下第一行是**钩子**，不是**点评**。范本初稿写"这是港股最大的单一持有人，没有之一"（评价），博格改成"这是港股最大持有人，再拆开看，更有意思"（钩子）——评价会让人停下来，钩子会让人往下滚。

### 6.3 数字写法与口径规范

- 百分比：涨幅跌幅带正负号、**全角制表**（"+65.4%" / "-72.9%"）；占比类写字面值（"37.8%"）。
- 明细行格式统一为 `名称＋占比，＋金额`（"外资 37.8%，17.7 万亿"）——**占比在前、金额在后**；数字与"万亿"之间加半角空格（"46.8 万亿"），**全篇统一**，别一处带空格一处不带。
- **"约"是口径标记，不是随手加的修饰词**：自洽口径直接给（"南向港股通 13.0%，6.08 万亿"），凡串联换算／折算／四舍五入得来的一律加"约"（"亚洲资金 47.7%，约 8.45 万亿"）。读者扫一眼就知道哪几个数是估算的。
- 大额换算成体感（"三年年化负73%是什么概念？投10万，三年后剩不到2万。"）——**加分项，不是必需项**。结构拆分型常用**比例对照**替代金额换算："三家加起来 24.5%，还不到外资的三分之二。"
- 小差异要放大："什么区别？就这0.03%，长期下来差出一辆车。"
- 规模用"亿美元"并给排序感（"规模 4976亿美元，流动性最好的那只"）。

### 6.4 收口公式（两个子形态共用）

数据短文**不收在情绪上**，也不要硬塞"我自己的实盘"（那是观点短文的收口，见第七节）——收在**一句能被截图引用的判断**上。顺序：

1. **设问引出**："港股定价权归谁？"
2. **分层给框架**（短期／中长期、边际／存量）："短期看外资的边际买卖，中长期才轮到南向。"
3. **趋势数据三连**（同一指标三个时点，用方向说话）："2024年末约 42.5%，2025年末 40.1%，现在 37.8%。"
4. **"但"字平衡**（说了一面，必须补反手）："但降的是比例，最大的底仓还在人家手里。"
5. **对仗短金句＋感叹号**（全文最可能被截图的一句）："最近几年基本上，外资卖、南向接！"
6. **博格观点句**（落点给方向，不给操作）："博格觉得，在未来几年，南向依旧是港股最大的资金来源。"
7. **求赞收尾**："统计数据不易，大家点赞支持~"

**只讲单边是硬伤**：讲了外资占比在降，就得说底仓仍在人家手里；讲了南向在买，就得说存量占比还不高。

### 6.5 避雷

- **不要**写"图里最后一列建议重点看"这类引导语——读者自己会看，说出来显得啰嗦。
- **不要**在短文里加"博格想说的"这种总结体小标题，短文体量承载不起，会显得头重脚轻。
- 短文**不写"先承认不确定"的铺垫**——那个转折属于观点长文，短文要的是干脆利落。
- **不要替读者预设情绪**：像「天天看到"南向爆买"，放到存量里就是这么个量级」「别看到一个外资撤离的标题就兴奋」这类替读者下结论的评论小段，一律删。把数据摆好，情绪读者自己会有。
- **不要把"免责解释段"写进正文**：口径多不可靠、测算误差多大，这是**图注**该干的活，正文里展开成段落会把节奏打断（博格改定港股那篇时，整段"关于欧盟资金，得说句实话"全删了——说明责任交给图注）。
- **编号按子形态用**：结构拆分型必须（1）（2）（3）；榜单排序型不编号，只用加粗短句小标题。

## 七、观点短文的收口（三种题材，三条路）

观点短文指"就一件事讲一段判断"的短帖（小红书高频），既不是日报周报，也不是数据榜单文。**按题材分三种，收口各不相同，不许混用。**

### 7.1 题材一：讲买卖时机 → 落回自己的实盘与动作

**核心原则：论证越悲观，越要落到自己的实盘与动作。**

- 悲观论证（"最艰难的时刻""谁强谁弱不好说"）本身没问题，是博格"承认无知"的底色。
- 但**不能停在悲观上**。必须补一句自己的仓位事实 + 一个由此推出的动作判断，把情绪从焦虑翻成从容。
- 范式：
  > 博格去年买的港股，现在已经亏损30%了。
  > 这时候可能是一个不错的买点~
- 这一句同时完成三件事：晒亏损（真实）、承认浮亏（不美化）、给出方向（行动）。**这是观点短文与"情绪贴"的分界线。**
- 收口位置在风险提示之前，风险提示压最后一行。

### 7.2 题材二：讲行业现象且与自己持仓相关 → 落回自己的应对框架

不喊买点，给仓位纪律或配置思路（"所以博格还是维持XX%仓位、均衡配置的思路"）。

### 7.3 题材三：讲自述处境（"这行越来越难干"）→ 把话筒递给读者

2026-10-03"赚钱越来越难"这一篇确立的新收口。**题材既不是买卖时机、也不是结构事实，而是博格自己的收入／处境在缩水。**

- **不需要给动作，也不该给买点**——这篇讲的根本不是市场，硬塞"这时候是个不错的买点"就跑题了。
- 收口＝**自曝之后邀读者一起晒**：
  > 博格的悲惨讲完了。
  > 大家有啥悲惨的事，也拿出来分享一下。
  > 欢迎留言聊一聊~
- 提问方式要注意：**别用投票式提问**（"大家觉得现在难了还是容易了"），那只会收到"难"一个字；**请读者讲自己的事**，评论区才有内容。
- **这类题材通常连风险提示也省**（正文无标的、无买卖倾向）。一旦补了倾向句，必须补回。
- 自嘲金句压观点句之前："以前总是听说别人钱难赚。今天终于轮到博格了。而且是一瞬间，冰封万里。"

**⚠️ 7.1 这条规则只适用于观点短文，别外溢到数据短文。** 博格改定港股持有人结构那篇时，把 AI 塞的整段"博格的做法／博格自己的港股仓位今年以来是……／看好的东西在低估的时候买"全删了，换成一句"博格觉得，在未来几年，南向依旧是港股最大的资金来源。"

判断口径：观点短文讲的是**买卖时机**，所以要落到自己的动作；数据短文讲的是**结构事实**，落到操作反而突兀、也容易变成变相荐股；自述处境短文讲的是**博格自己**，落到共鸣。三者的收口分别见 7.1／7.3 与 6.4。
